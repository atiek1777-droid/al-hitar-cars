# AL-HITAR CARS — الهتار كارز

موقع فاخر لشركة الهتار كارز للسفريات وتأجير السيارات في صنعاء، مبني كموقع ثابت (Static HTML/CSS/JS) — بدون حاجة لأي عملية بناء (build)، وقابل للنشر مباشرة.

## هيكل المشروع

```
site/
├── index.html          الرئيسية (فيديو الواجهة + الشريط المتحرك + معرض مصغر)
├── fleet.html           الأسطول الكامل (65 سيارة + فلاتر)
├── travel.html          خدمات السفر والحج والعمرة
├── contact.html         نموذج الحجز + التواصل
├── offline.html         صفحة عدم الاتصال (PWA)
├── manifest.webmanifest إعدادات تثبيت التطبيق (PWA)
├── service-worker.js    التخزين المؤقت للعمل بدون إنترنت
├── vercel.json          إعدادات النشر على Vercel
├── robots.txt / sitemap.xml
├── css/style.css        كل التصميم والحركات
├── js/main.js           كل السلوك التفاعلي (القوائم، الفلاتر، النموذج، PWA)
└── assets/
    ├── images/cars/      65 صورة سيارة محسّنة (jpg + webp)
    ├── images/action/    13 صورة "ميدانية" بعد قص العلامة المائية وتحسين الدقة
    ├── images/logos/     5 شعارات ماركات (Ford, BMW, Lexus, Mercedes, Toyota)
    ├── images/originals/ كل الصور الـ83 الأصلية كما رفعتها (بدون أي تعديل)
    ├── fonts/            heading.ttf (BoutrosART) و body.ttf (Tajawal)
    ├── video/            hero.mp4 (معاد ترميزه) + hero-poster.jpg
    └── icons/            كل أيقونات PWA + og-image

```

## الخطوط المستخدمة

- **العناوين:** BoutrosART Medium (من ملف `heading.ttf` الذي رفعته) — خط عربي فخم للعرض.
- **النصوص:** Tajawal Medium (من ملف `body.ttf` الذي رفعته) — خط عربي حديث وواضح للقراءة.
- تم اختيارهما لأنهما كانا مسمّيين صراحة `heading.ttf` / `body.ttf` داخل أرشيف الخطوط، وهو ثنائي احترافي شائع في تصاميم العلامات الفاخرة.

### بخصوص الـ13 صورة الميدانية
هذه الصور كانت في الأصل لقطات فيديو منخفضة الدقة (640×480) وعليها علامة مائية لجهة أخرى ("DUBI CARS"). بناءً على تعليماتك، تم:
1. قص الشريط الجانبي المموّه (الحواف المكررة) والاحتفاظ بالجزء الحاد فقط من كل صورة.
2. قص/إزالة الشريط العلوي الذي يحتوي العلامة المائية بالكامل.
3. تكبير الصورة الناتجة (~2.4x) وزيادة الحدة لتحسين وضوحها قدر الإمكان نظرًا لأصلها منخفض الدقة.
4. وضعها في قسم منفصل بعنوان "أسطولنا على الطريق" بدل خلطها مع صور الاستوديو عالية الدقة، لأن جودتها مختلفة طبيعيًا عن باقي الصور.

جميع الصور الأصلية الـ83 دون أي تعديل موجودة أيضًا في `assets/images/originals/` لسهولة الرجوع إليها.

## لون العلامة التجارية

تم استخراج اللون الفعلي من الشعار المرفوع: **`#00A692`** — وهو المستخدم في كل تفاصيل التصميم (الأزرار، الشريط المتحرك، الحدود...).

## بيانات السيارات

لا تحتوي الصور المرفوعة على بيانات نصية (الماركة/الموديل/السعر)، لذا لم يتم اختراع أي بيانات. كل سيارة معروضة بتصنيف عام (دفع رباعي / بيك أب / صالون / رياضية) واستُبدلت الأسعار بزر "استفسر عن التفاصيل" يفتح واتساب مباشرة مع اسم السيارة المحددة.

## ماذا لم يُبنَ (وليه)

- **لا يوجد تبديل لغة كامل (عربي/إنجليزي):** طلبك الأساسي حدد العربية كلغة أساسية للموقع؛ تم إبقاء عناصر إنجليزية للعلامة التجارية (الاسم، الشعار) دون بناء نظام ترجمة كامل، لتوفير الوقت والتركيز على الميزات المطلوبة صراحة. يمكن إضافته لاحقًا كخطوة منفصلة إن أردت.
- **لا خرائط Google API حية:** استُخدم تضمين خرائط Google العام (بدون مفتاح API) بعنوان الشركة النصي — يعمل مباشرة بدون أي إعداد إضافي.
